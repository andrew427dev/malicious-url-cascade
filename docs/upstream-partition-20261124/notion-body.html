이번에는 학습·검증·시험 집합 안에서 전처리한 전체 URL 문자열이 같을 때 첫 행만 남겼다. 원래 표기의 무작위 시험에서 가장 빠른 캐스케이드인 히스토그램 기반 그래디언트 부스팅(HGB) 경계의 1,000건 처리 중앙값은 38.59 ms였다. 같은 URL의 게이트 순환 유닛(GRU) 단독은 42.31 ms로, 캐스케이드에서 3.72 ms 줄었다. 캐스케이드는 전체 시험 112,984건에서 악성을 451건 더 놓쳤다.

Introduction & Motivation

모든 주소에 신경망을 실행할 때와, 정상 가능성이 큰 주소의 검사를 앞단에서 끝낼 때의 차이를 측정했다. 비교 단위는 같은 전체 시험에서 추가로 놓친 악성 수와 같은 1,000건 배치에서 실제 절약한 시간이다.

Experiments (highlighting your extension settings)

로지스틱 회귀(LR)는 계산이 가벼운 선형 분류기이고 히스토그램 기반 그래디언트 부스팅(HGB)은 수치 특징의 비선형 관계를 학습하는 트리 모델이다. 둘은 같은 1단계의 대안이다. 같은 분할·표기의 주 비교 7개 구성은 같은 GRU를 사용한다.

전체 모델 구성도

18개 수치 → LR 또는 HGB → 임계값 이상은 GRU, 미만은 정상 종료 후보. 후보 중 무작위 또는 경계에 가까운 5%를 GRU에 보낸다. GRU는 선택된 주소의 문자 3그램과 18개 수치를 함께 받아 최종 판정한다.

5%는 조기 종료 후보 수를 분모로 내림한다. 공통 검증 집합에서 모델을 선택하고 확률 보정과 임계값 결정을 마쳤다. 네 조건을 고정한 뒤 본 시험을 수행했다. 시간은 14개 구성 예열 후 5회 순서를 섞어 원본 URL에서 판정까지 측정했다.

초기 준비 실행에서 보조 기준선의 시험 점수가 먼저 산출됐다. 최종 비교에는 경량 모델을 다시 학습하고 네 조건의 분기 기준을 검증 집합에서 모두 고정한 뒤 계산한 수치를 사용했다.

미탐 허용 범위를 검증 자료에서 먼저 정하고 임계값을 낮추거나 재검사 비율을 높이면 신경망이 더 많은 주소를 검사한다. 각 조건의 실제 시간과 추가 탐지 수를 함께 확인해야 한다. 이번 측정은 단일 학습 시드와 한 CPU에서 처리한 배치에 해당한다. 원저자 별도 파일도 학습·검증 원문과 겹친다.

Conclusion and References

무작위 분할의 원래 접두 표기를 유지한 조건에서 가장 빠른 캐스케이드는 HGB 경계였다. GRU 단독과 비교한 1,000건 처리 시간 중앙값은 3.72 ms(8.79%) 짧았고, 전체 시험에서 악성을 451건 더 놓쳤다.

무작위 분할의 접두 표기 통일 후 재학습한 조건에서 가장 빠른 캐스케이드는 LR 경계였다. GRU 단독과 비교한 1,000건 처리 시간 중앙값은 1.44 ms(3.46%) 짧았고, 전체 시험에서 악성을 218건 더 놓쳤다.

11월 23일 보고서는 최종 모델 입력이 같은 행을 전역에서 제거했고, 표기 통일 때 충돌 그룹을 제외해 무작위 시험에서 345행이 더 빠졌다. 이번에는 집합 안의 전처리 전체 문자열을 기준으로 첫 행만 남겼다. 분할 전 모집단과 시험 대상이 달라져 두 날짜의 재현율이나 시간을 빼서 캐스케이드의 개선량으로 볼 수 없다.

이전 보고서에서는 표기 통일 후 HGB 경계 재검사로 호출이 줄어도 1,000건 처리 시간이 늘었다. 이번 같은 유형의 비교에서는 GRU 단독 대비 호출 190건 감소, 시간 1.10% 증가, 전체 시험의 추가 미탐 356건을 관측했다. 같은 실험 안에서 세 수치를 함께 봐야 분기 비용을 판단할 수 있다.
